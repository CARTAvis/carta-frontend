# Channel map refactoring review

Reviewed `kuanchou/channel_map_refactoring` (`30f4056e405`) against local `dev` (`7af6cecd47`), plus the follow-up working-tree fixes. The final pass found no remaining actionable findings in the reviewed diff.

## Findings resolved

| Area                               | Finding                                                                                                                                                                                                                                                                                                                  | Resolution                                                                                                                                                                                                                                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Normal viewport requests           | Panning during a channel or Stokes transition could request tiles for the previously displayed selection. The backend can also replace a queued `SetImageChannels`, dropping its tiles.                                                                                                                                  | Resolve the selection when the viewport request is sent. Carry forward tiles still needed by the current viewport when replacing an unstarted request. Use an explicit selection until a raster sync confirms it.                                                                                                  |
| Raster stream and worker lifecycle | Late packets could recreate retired sync state. A worker result could be accepted while a replacement request for the same tile was pending. Animated sync streams also had `viewGeneration === 0` with an empty generation map, preventing `flush`.                                                                     | Associate raster streams with recorded requests, clear retired state on cancellation and animation changes, match decompression results by request ID, and default missing view generations to `0` in `completeSynchronisedTiles`.                                                                                 |
| Channel-map queue and mode sync    | Refreshing the viewport could drop in-flight tracking, changed channel lists could go unsent when cached, a cached Stokes transition could duplicate the active channel request, and enabling channel-map mode or shrinking the grid could leave `frame.channel` / `frame.stokes` behind pending `required*` selections. | Keep requests tracked until streams settle, include requested channel lists when matching in-flight selections, avoid appending duplicate active-channel requests when no other channels are queued, clear `rasterRequest` on synthesized Stokes transitions, and promote pending/fallback selections immediately. |
| Loading and overlays               | Off-page tiles could hold loading open, unrelated files could clear channel-map progress, overlays could reveal mismatched channels, and restarted or cleared contour/vector streams on the same channel could append to stale buffers or stay marked current.                                                           | Count pending tiles for visible files, scope channel-map progress to its target file, gate contours/vector overlays on stream activity flags and displayed selection, and reset readiness on clear.                                                                                                                |
| Animation                          | A server acknowledgment arriving after Stop could re-enable tile animation, and `handleTileStream` skipped updating `channel`/`stokes` on spectrally matched sibling frames.                                                                                                                                             | Ignore superseded starts and re-send Stop if needed. Split flow-control sending (`activeFrameFileId`) from updating `channel`, `stokes`, `requiredChannel`, and `requiredStokes` for all animated frames.                                                                                                          |
| Alerts                             | An informational alert could replace an interactive prompt without resolving it, and a timeout prompt could survive a session reset.                                                                                                                                                                                     | Queue alerts in arrival order and dismiss timeout prompts when retiring requests or resetting for session resume.                                                                                                                                                                                                  |

## Refactoring and performance suggestions applied

- Reused `FrameStore.requiredTiles` for tile requests, raster rendering, and animation startup. Channel maps sort each viewport once and reuse that order across its channels.
- Removed the duplicate active-channel request path, delegated `TileService.resetForSessionResume` to `cancelChannelMapRequests()` + `resetRasterRequests()`, simplified `AlertStore` Escape-key handling, and reused the request ID echoed by the worker.
- Limited raster redraw notifications to panel files, displayed channel-map channels, and matching normal-view channel/Stokes selections; skipped compressed cache lookups when tiles are on the GPU or already pending.
